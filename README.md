## Featured Projects

### [LearnHub API](https://github.com/brunobaldiga/learnhub)

A REST API for an online learning platform, built using a **modular monolith architecture** with domain-oriented modules.

- JWT authentication and role-based authorization.
- Course management, purchases, enrollments, and progress tracking.
- Multi-currency payments with external API integration.
- Automated testing with JUnit, Mockito, and Testcontainers.
- CI with GitHub Actions and deployment on Render.

**Tech Stack:** Java 21 · Spring Boot 4 · Spring Security · PostgreSQL · Flyway · Docker · JUnit · Testcontainers · GitHub Actions

### [Java Bank](https://github.com/brunobaldiga/java-bank)

A banking application developed to strengthen Core Java, object-oriented programming, and software architecture skills.

- Checking and savings accounts.
- Deposits, withdrawals, and transactional transfers.
- JPA/Hibernate persistence and database migrations.
- Password hashing with PBKDF2.
- JavaFX desktop interface planned.

**Tech Stack:** Java 21 · JPA · Hibernate · PostgreSQL · Flyway · HikariCP · Docker Compose
